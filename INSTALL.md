In order to install the CLI and compile, the following dependencies are required:
- G++ compiler
- Make
- C++ runtime

# STEP ONE:
Download ZIP file of repository from Github and Unzip downloaded folder
# STEP TWO:
Using a shell, navigate to the unzipped directory
# STEP THREE:
In the unzipped directory, use the command 'make'
# Required Components:
- The Stockfish executable is pre-compiled in the /stockfish/ dir
- The Chess executable, post compilation
