#Setup

The releases page at the following link contains the chess executable and the stockfish executable
https://github.com/ZeferinoA/Chess_plusplus/releases/tag/release

#STEPS FOR SETUP:
1. Make new folder in Chess directory titled: "stockfish"
2. place the stockfish executable in this folder
3. doing so will allow the program to run when "chess" is input into the terminal

This stockfish executable is not tagged .exe and therefore will not run on Windows machines
for Windows machines, you should download and compile at the following repo link
https://github.com/official-stockfish/Stockfish
